# 管理后台

独立 Web 管理端，通过后端 API 提供获批的管理功能，对接独立的 happyAnyway-admin-api 管理后端，不直接连接数据库。

技术栈已确认：Vue 3 + TypeScript + Vite + Element Plus + Vue Router + Pinia + Axios。当前仅完成架构和岗位配置，尚无页面、依赖或可运行工程。认证方式和业务范围尚待确认，不预设登录或管理模块已经实现。

- [路书与文件用途](ARCHITECTURE.md)
- [开发岗位](agent.md)
- [开发规则](docs/rules/development.md)
- [功能开发文档](docs/development/README.md)

代码质量工具已确认：ESLint + Prettier。ESLint 用于代码规范检查，Prettier 用于统一格式；生成工程时配置适用于 Vue 3 与 TypeScript 的规则并避免格式规则冲突。交付执行代码检查、格式检查、独立类型检查及构建，不以其中一项替代其他检查。当前尚未创建工具配置或运行检查。

单元与组件测试方案已确认：Vitest + Vue Test Utils。围绕实际业务行为、组件交互及异常分支编写测试；不预建无功能的测试，不以仅验证模拟调用的断言代替行为验证。组件测试不能代替真实浏览器、接口联调或权限验证。生成工程时再建立实际依赖和执行脚本，当前不宣称测试已运行。

浏览器端到端测试使用 Playwright，按已确认功能验证关键页面流程、交互和失败路径；使用隔离测试环境与数据，不对生产数据执行破坏性操作。依赖、浏览器及测试脚本在工程建立时配置，未执行或受阻项如实说明。模拟接口场景与真实后端联调明确区分，不能互相替代。
