## 技术协调决定

- 网页采用 P0 主推的 Vue 3、TypeScript、Vite、Vue Router、Element Plus，依赖兼容版本由网页岗位根据官方文档核对并锁定。此为既有后台范围内的工程选择。
- 接口统一使用 /api/v1 前缀，金额字段统一 costFen，不使用 amountFen；错误统一 code/message/requestId/fieldErrors，字段校验用 HTTP 400；采用后端 P0 路径方案，管理员入口 /api/v1/admin/auth/session、审核决定 /api/v1/admin/reviews/{id}/decision。
- 时间为 UTC ISO 8601；ID 为字符串；文本 trim 后按 Unicode 码点计数。列表统一 items/nextCursor，nextCursor 为 null 表示结束，不另设 hasMore。
- 服务检查失败保持待检查，不开放人工直接通过；已确认的异常内容转人工流程保持不变。
- 用户会话建议固定 7 天，管理员会话建议固定 8 小时，均需再次登录续接，不自动重放写请求；幂等记录建议保留 24 小时。这些作为待冻结的接口参数，由后端核对实施风险。
- 图片参数草案：JPEG/PNG、10 MiB/张、解码后最多 4000 万像素。上传和预览必须鉴权，不通过公开 URL 暴露待审图片。后端需明确跨端可行的预览方式，前端不自行假设 image 标签能传 Bearer header。
- 下架后编辑重提规则仍等待用户决定；只暂停依赖这一规则的代码。停用分类的编辑规则及外部服务能力在接口冻结前明确。
