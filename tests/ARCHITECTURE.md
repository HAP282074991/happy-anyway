# 独立测试结构路书

维护岗位：独立测试 Agent；岗位权限与公共规则由项目经理维护。最近核对：2026-10-08；对应当前主工作区，隔离测试成果以任务交接版本为准。

本目录保存岗位配置、测试规则及路书。后续辅助脚本、用例和数据按任务置于 tests/<任务主题>/；必要的工具原始报告、日志和截图按交接指定位置保存并引用，不预建空目录。人工问题清单及复测结论由项目经理汇入当前任务记录，不另建人工报告；记录方式遵循[项目记录规则](../docs/rules/task-records.md)。规划路径不表示已经落地。

验证流程：已确认需求与准确版本 → 测试用例和环境 → 执行证据 → 报告与缺陷回流。业务修复交原开发岗位；不通过修改产品逻辑让测试通过。工程内单元测试分别位于后端 src/test/ 和 App 实际测试目录，不在此重复维护。

新增测试套件时记录套件入口、运行命令所在文档、环境与数据依赖、证据位置和清理边界；不保存密钥或真实敏感数据。具体命令随任务验证后登记，不预写未经核验的执行方式。

接单依据：[岗位配置](agent.md)、[测试规则](rules.md)、[测试交接](../docs/rules/test-handoff.md)。维护遵循[路书维护规则](../docs/rules/project-roadmap.md)。
